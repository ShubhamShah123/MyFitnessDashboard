
# MyFitnessDashboard

Admin-focused fitness management dashboard designed to monitor user activity, workout progress, nutrition tracking, and overall fitness analytics. The project is part of a larger fitness ecosystem that also includes a companion mobile application for end users.

---

## Overview

MyFitnessDashboard allows administrators to manage and visualize fitness-related data through a clean and responsive dashboard interface. The platform is built with scalability in mind and is intended to support future AI-driven insights and advanced analytics features.

The companion mobile application enables users to:
- Track workouts
- Log meals and nutrition
- Monitor body measurements
- Start workout sessions
- View fitness progress

## Installation

Clone the repository:

```bash
git clone https://github.com/ShubhamShah123/MyFitnessDashboard.git
```

Navigate into the project directory:

```bash
cd MyFitnessDashboard
```

Install dependencies:

```bash
npm install
```

---

## Running the Project

Start frontend dashboard:

```bash
npm run dev
```

Start expo app:

```bash
npx expo start
```
